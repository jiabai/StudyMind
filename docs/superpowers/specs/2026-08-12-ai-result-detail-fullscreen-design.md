# 学习整理详情窗口全屏设计

## 状态

已获用户确认。范围限定为现有学习整理结果详情窗口的应用内全屏显示。

## 目标

在学习整理卡片的“查看结果”详情中增加全屏/还原操作，解决知识结构 Markdown 内容较长时弹窗可视区域偏小的问题。预览态和编辑态必须继续共用同一个详情窗口，不新增窗口、路由或独立编辑页面。

## 交互设计

1. 用户点击“查看结果”后，仍由现有 `AiResultDetailSheet` 显示结果。
2. 详情窗口标题栏增加全屏按钮。
3. 点击全屏后，当前详情容器铺满应用内容区域；当前结果类型、编辑草稿、编辑/预览模式和未保存状态全部保持不变。
4. 点击还原后，详情容器恢复原有弹窗尺寸。
5. 关闭详情时退出全屏状态；再次打开结果时从普通弹窗尺寸开始。

## 实现边界

- 在 `AiResultDetailSheet` 内维护全屏状态，并将全屏 class 应用到现有 dialog section。
- 预览态与编辑态复用同一个 dialog、遮罩、焦点管理和关闭保护逻辑。
- 在 `App.css` 中增加全屏详情窗口的尺寸和圆角规则；不实现操作系统级 F11 全屏。
- 在 synthesis 命名空间中增加简体中文、繁体中文和英文的全屏/还原无障碍文案。
- 不改变结果读取、编辑保存、复制、导出、重新生成和任务状态逻辑。

## 无障碍与响应式

- 全屏按钮使用本地化 `aria-label`，图标只作为视觉提示。
- 现有 `role="dialog"`、`aria-modal`、焦点陷阱和遮罩关闭行为保持不变。
- 全屏窗口仍允许内容区域滚动，窄窗口下继续复用现有工具栏响应式布局。

## 验证

- 组件测试验证全屏按钮文案在各支持语言下可渲染，并确认全屏状态 class 作用于同一详情 dialog。
- 运行结果详情相关 Vitest 测试、前端 lint/build；若全量测试可运行，再运行前端测试套件。
